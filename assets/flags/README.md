# Country flags

SVG flags from [flag-icons](https://github.com/lipis/flag-icons/tree/086f7e97d657358203916dbe84f61c2bccaa81eb), used under the [MIT license](LICENSE). Source: `flags/4x3/`. Display size is 32 × 24. Reused SVG elements are expanded into inline shapes for renderer compatibility; US stars use explicit polygons instead of SVG markers. Original view boxes and country designs are retained.
